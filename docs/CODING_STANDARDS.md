# 编码体系与版本口径

[English](CODING_STANDARDS.en.md)

## 结论

**本项目不内嵌、也不锁定某一版 ICD 全量编码表。** 这不是遗漏，是核查后的确定结论。

国家医保局发布的《按病种分值（DIP）付费 3.0 版分组方案》xlsx 只含**病种目录与编码片段**（主要诊断编码、手术操作编码、其他诊断编码等列），不含 ICD-10 / ICD-9-CM-3 医保版的全量编码字典。全量编码表由另一套机制单独维护：

| 项 | 内容 |
|---|---|
| 官方来源 | 国家医保信息业务编码标准数据库动态维护平台 `https://code.nhsa.gov.cn/` |
| 诊断编码查询 | `https://code.nhsa.gov.cn/jbzd/public/dataWesterSearch.html`（ICD-10 医保版） |
| 手术操作编码查询 | `https://code.nhsa.gov.cn/jbzd/public/dataOperationSearch.html`（ICD-9-CM-3 医保版） |
| 编码规则 | 《医保疾病诊断和手术操作、药品、医疗服务项目、医用耗材四项信息业务编码规则和方法》<br>`https://code.nhsa.gov.cn:8000/lib/img/file1/attachment.pdf` |
| 全量数据获取 | 平台「医保疾病诊断、手术操作分类与代码数据库」→「数据下载」模块；新版数据库同步通过国家医保信息平台推送至各地 |
| 维护性质 | **动态维护**，无单一固定版本号 |

## 版本口径（截至 2026-11-06 核查）

1. **医保版 2.0 是历史基线**：各地自 2021-10-01 起陆续启用「医保疾病诊断分类与代码 ICD-10（2.0 版）」「医保手术操作分类与代码 ICD-9-CM-3（2.0 版）」。这是公开文件中可查到的静态版本号。
2. **2.0 之后已有正式调整**：`医保办函〔2025〕141号`《关于进一步做好医保疾病诊断、手术操作分类与代码应用工作的通知》（2025-12-31 印发、2026-01-19 公开）调整优化了医保手术操作分类与代码，新增 7 个、修订 4 个聚焦超声相关代码；新版数据库已推送各地并可从动态维护平台下载。
3. 因此 **「ICD 医保版 2.0」不足以代表 DIP 3.0 落地时使用的编码库**。把它写死进项目会产生一个看似确定、实际过期的版本号。

## 本项目的处理

- 可复现性锁定对象是**官方 DIP 3.0 分组方案 xlsx 本身**：SHA256 `dec2b17b8f277bec8153d8d8922380e8145ca420dc90758bcb45ad2a98a5dc7d`，594645 字节，随仓库分发。
- 编码列按原样结构化，不补全、不映射、不推断编码名称；`|` 多编码拆开、`-` 区间码单列，均保留官方原始写法。
- 编码体系作为**外部动态标准**显式声明来源与核对入口，不声称与某一静态版本严格对应。
- 使用者若要做真实病案入组或 ICD 映射，须自行从动态维护平台获取当前有效版本并核对地方实施细则；本仓库不提供该能力，也不提供再授权（见 `DATA_NOTICE.md`）。

## 编码结构（来自官方编码规则文件）

- **ICD-10 医保版**：前 3 位为类目（1 位大写字母 + 2 位数字），第 4 位为亚目，第 5、6 位为延拓的区分码（条目）。
- **ICD-9-CM-3 医保版**：全数字，前 2 位类目（手术章节）、第 3 位亚目、第 4 位细目、第 5、6 位延拓区分码。
- 这与官方 xlsx 中出现的 `A01.0`、`C00-C75`、`44.1300x001` 等写法一致；`x` 后缀属于地方/临床扩展写法，本仓库按原样保留，不做规范化。

## 核查依据

- `医保发〔2026〕22号`《关于印发按病组和病种分值付费 3.0 版分组方案并做好落地实施相关工作的通知》（2026-09-02，nhsa.gov.cn）：正文与附件未附 ICD 全量编码表，也未指定编码版本号。
- `医保办函〔2025〕141号`（2025-12-31）：手术操作分类与代码调整说明、新版数据库推送与下载方式。
- 国家医保信息业务编码标准数据库动态维护平台：查询页与编码规则 PDF（见上表）。
- 浙江省 2021 年启用 2.0 版通知等地方公开文件：用于确认 2.0 版的历史起点，不作为当前版本依据。
